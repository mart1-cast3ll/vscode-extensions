# Changelog

## 0.1.0

- Custom editor for `*.md` / `*.markdown` with GitHub-style rendering.
- Click-to-edit blocks and `+` buttons to insert new blocks.
- Clickable task list checkboxes.
- Formatting toolbar, keyboard shortcuts, list continuation and indentation.
- Side-by-side source pane and heading outline.
- Relative links and images resolved against the document folder.
