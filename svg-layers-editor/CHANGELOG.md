# Changelog

## 0.2.0

- Exported image area grows to fit every visible object; **Show image bounds** toggle.
- Open, Save, Download SVG, Undo and Redo buttons.
- Open SVG files by dropping them onto the editor (`Shift` + drop).
- Move layers out of groups and drag layers between groups.
- Color wheel, opacity and scale sliders, rotation dial.
- Code panel linked to the selection.
- Syntax errors reported with line and column; canvas locked until fixed.
- Code split into modules.

## 0.1.0

- Custom editor for `*.svg` with layers panel, move/rotate/scale, group/ungroup, reorder, duplicate, delete, hide and rename.
- PNG export.
