# VS Code Extensions

Visual Studio Code extensions by [mart1-cast3ll](https://github.com/mart1-cast3ll). Each folder is a standalone extension with its own README, changelog and releases.

| Extension | Description | Latest |
| --- | --- | --- |
| [SVG Layers Editor](svg-layers-editor/) | Open any SVG as layers: move, rotate, scale, regroup and recolor, with a linked code view. | [v0.2.0](https://github.com/mart1-cast3ll/vscode-extensions/releases/tag/svg-layers-editor-v0.2.0) |

## Installing an extension

Download the `.vsix` from the extension's release, then in VS Code open **Extensions** → `⋯` → **Install from VSIX…**, or run:

```bash
code --install-extension <file>.vsix
```

## Releases

Release tags are prefixed with the extension folder name, for example `svg-layers-editor-v0.2.0`. See [all releases](https://github.com/mart1-cast3ll/vscode-extensions/releases).
